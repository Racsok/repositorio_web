# Requerimientos Preliminares del Portafolio Web
Estos requerimientos están pensados para un perfil técnico (enfocado en ingeniería de datos, backend y automatización), 
asegurando que el sitio sea rápido, ligero y fácil de mantener.

## Alcance y Objetivos
* Objetivo principal: Presentar de forma clara tus habilidades técnicas (Python, SQL, Linux, Git, bases de datos), 
proyectos destacados (como tu API en Spring Boot, pipelines de CrewAI o análisis estadísticos en R) y medios de contacto para conseguir 
prácticas profesionales o empleo en ingeniería de datos.

* Público objetivo: Reclutadores técnicos, líderes de desarrollo e ingenieros de datos.

## Requerimientos Funcionales
1. Sección "Sobre mí / Perfil": Breve introducción profesional, tu enfoque actual (estudiante de ingeniería de sistemas finalizando carrera) 
y enlaces directos a tu GitHub y LinkedIn.

2. Sección de Proyectos: Tarjetas o listado con tus proyectos más representativos. Cada proyecto debe incluir:

3. Título y descripción breve.

4. Tecnologías utilizadas (ej. Python, PostgreSQL, CrewAI, LaTeX).

5. Enlace al repositorio de código fuente.

6. Sección de Habilidades (Stack Tecnológico): Categorización limpia de tus competencias (Lenguajes, Bases de Datos, Herramientas DevOps/Linux, Frameworks).

7. Curriculum / CV descargable: Un enlace o botón para visualizar/descargar tu hoja de vida en PDF.
